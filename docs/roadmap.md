# Roadmap

## Phase 1
- Daily FTSE 100/LSE data ingestion
- Technical feature engineering
- XGBoost baseline model
- Chronological backtest
- FastAPI health and protected user endpoint
- Azure Key Vault integration
- GitHub Actions CI

## Phase 2
- RNS/news ingestion and NLP features
- FTSE sector and macro features
- GBP/USD and gilt-yield context
- Better calibration and walk-forward validation
- Model registry and experiment tracking

## Phase 3
- Event Hubs streaming ingestion
- Licensed real-time market feed
- Intraday/order-book features
- Paper broker integration
- Dashboard and alerting

## Phase 4
- Optional live execution only after extensive validation and controls
